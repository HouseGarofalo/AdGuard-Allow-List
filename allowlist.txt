! ===========================
! ✅ CI / Build Toolchain Downloads (.download TLD)
! ===========================
! The whole .download TLD is null-routed by the upstream blocklists — verified
! 2026-08-28 by asking the resolver for a domain that does not exist:
!
!   temporal.download -> 0.0.0.0     (real, needed)
!   nodejs.download   -> 0.0.0.0     (real, NodeSource)
!   cdn.download      -> 0.0.0.0     (INVENTED — should be NXDOMAIN)
!
! That third line is the proof it is a wildcard TLD rule and not three separate
! entries. Keep the TLD blocked and allow only what is actually needed; do NOT
! add @@||*.download^ — the blocklists include that TLD for good reason.
!
! Symptom when this bites: the failure is a *download*, so it surfaces as a build
! or CI error rather than a DNS one, and only when a cache is cold. It took out
! self-hosted CI for HouseGarofalo/atlas-media with no code change — the runner
! caches the binary by version, so it was invisible until that cache expired.
! Temporal test-server binary (temporalio SDK, CI)
@@||temporal.download^$important
